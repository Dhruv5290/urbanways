# UrbanConnect Digital Marketing Website

## File Structure

This is a multi-page website with the following pages:

- `index.html` - Homepage (Hero, Portfolio, Testimonials)
- `services.html` - Services page with 6 detailed services
- `about.html` - About page with team, values, company info
- `contact.html` - Contact page with form, map, FAQ
- `style.css` - All styles for all pages
- `main.js` - JavaScript for all pages

## How to View

1. **Locally**: Open `index.html` in a web browser, then click navigation links
2. **Deploy**: Upload all files to a web server (they must be in the same directory)

## Navigation

Each page has a header navigation menu that links to:
- Home → index.html
- Services → services.html
- About → about.html
- Contact → contact.html

All pages are separate files that can be accessed independently!
